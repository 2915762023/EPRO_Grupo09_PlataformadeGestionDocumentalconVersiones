Plataforma de gestión documental con versiones

Este sitio web funciona como un repositorio centralizado donde se podrán subir distintas versiones mejoradas de documentos organizacionales para que estos puedan ser aprobados y que todos los usuarios puedan tener acceso a estos. 


Instalación del Proyecto: 

Backend
npm install
npm start


Frontend
npm install
npm run dev


Configuración de Base de Datos
1.	Crear base de datos MySQL. 
2.	Importar script SQL. 
3.	Configurar credenciales en: db.js
